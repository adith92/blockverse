# 🚀 BLOCKVERSE Next-Upgrades Roadmap (Proposal only)

## Highest priority
1. **📱 Mobile HUD overhaul**: minimap collapsed by default, nonoverlapping joystick, safe-area landscape/portrait, real Android/iPad benchmarks.
2. **🧑‍🏫 NPC learning quests**: curriculum-aligned mini-lessons, quizzes, feedback and badges, with *server-validated* progress. Current NPCs deliver safe static/LLM-assisted lessons only.
3. **🔊 Natural Indonesian local voice pack**: verify license, correct pronunciation and youthful synthetic timbre, proper TTS cache and latency measurements.
4. **🛡️ Child protection**: independent moderation classifier + rules, parent consent dashboard, reporting and emergency contact guidance, minimal retention. Before public freeform AI.
5. **⚡ Performance**: reduce draw calls, improve LOD/instancing, touch camera occlusion, test on low-end Android.
6. **🌐 Multiplayer server authority**: robust position validation, server-side movement/collision, anti-spam and reconnect, Redis or database for multiple nodes.

## More playful learning features
7. **📚 Classrooms per district**: Bahasa Indonesia, IPA, IPS, mathematics, art, local culture, quizzes with progress.
8. **🗺️ Jakarta missions**: local history and geodata clearly distinguished from fictional playground; license/attribution for OSM.
9. **🧏 Accessibility**: subtitles always visible, font size control, screen-reader labels, motion reduction, mute by default.
10. **🎙️ Optional speech input**: only with explicit guardian opt-in and on-device/local Whisper.cpp ASR, no recordings stored.
11. **🎨 Voice-synced facial animation**: NPC mouth morph targets/blendshapes and gesture animations, disabled on low-end phones.
12. **🧑‍🤝‍🧑 Cooperative school**: group puzzles using safe predefined phrases, restricted communication and anti-harassment.
13. **🏗️ School Builder**: create classrooms and science gardens using curated world prefabs.
14. **🧠 Personalization without PII**: optional progress badges stored pseudonymously, no personal profiles by default.
15. **📈 Privacy-preserving learning dashboard**: aggregate accuracy, performance and uptime; no storing full child questions.
16. **🎞️ Higgsfield-assisted concept art**: generate character references / animations / promo materials, but not a native GLB producer; licensed originals only.

## Recommended implementation order
**P0** safety, QA and mobile UI → **P1** voice Indonesian + scripted quizzes → **P2** locally moderated open tutoring + accessibility → **P3** server-authoritative multiplayer and 3D cinematics.

These are **recommendations**, NOT features currently completed. Ask the project owner before implementing future work.
