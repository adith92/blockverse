Dokumentasi Proyek: TASKS, DECISIONS, ROADMAP & QA_REPORT

Ringkasan arsitektur, kontrak data, dan status verifikasi P0/P1 sesuai spesifikasi PRD.

1. TASKS.md (Status P0 & P1)

  • ✅ [P0] Boot flow, Home menu, Pause/Settings, Audio synthesizer, Error recovery
  • ✅ [P0] Sunrise Plaza 3D Hub + Air Mancur Kristal + 3 Portal Interaktif
  • ✅ [P0] Karakter Blocky 3D + Fisika AABB/Ramp + Kamera Orbit + Respawn
  • ✅ [P0] Sky Obby: 15 Rintangan di 3 Bagian, 3 Checkpoint, Hazard, Timer & PB
  • ✅ [P0] Builder Island: 8 Objek, Raycast Ghost, Transform, Cat, Undo/Redo, Test Mode
  • ✅ [P0] Persistensi: Revisi Dunia, Otorisasi Pemilik, Penyimpanan Cloud/IndexedDB
  • ✅ [P0] Multiplayer: Sinkronisasi Ruangan Real-Time (Firestore + BroadcastChannel)
  • ✅ [P0] Editor Avatar: 6+2 Warna, 4 Aksesori Prosedural, Quick-Chat Aman
  • ✅ [P1] Kontrol Sentuh Mobile (Joystick + Tombol) & Mini-Game Coin Dash

2. DECISIONS.md (Keputusan Teknis)

  • Mesin 3D & Fisika: Three.js dengan simulasi fisika di browser. Performa dan collision perlu diuji pada perangkat nyata.
  • Multiplayer: BroadcastChannel untuk tab lokal, Firestore untuk perangkat terpisah jika diaktifkan. Batas 16 pemain belum ditegakkan server-side.
  • Keamanan Konten (Child-Safety): Tanpa chat bebas; hanya kode Quick-Chat terverifikasi. Skema dunia memvalidasi batas koordinat (-120..120), skala (0.5..20), dan kuota (<=300).

3. ROADMAP.md (Batas P2 Backlog)

Fitur P2 berikut sengaja tidak diklaim di MVP sesuai kontrak PRD:

  • Eksekusi skrip Lua / kode pengguna di dalam dunia.
  • Marketplace berbayar atau mata uang kripto.
  • Voice chat & unggah tekstur bebas tanpa moderasi manusia.
  • Simulasi fisika penuh di sisi server untuk anti-cheat tingkat turnamen.

4. Skema Validasi & Keamanan

World cloud dibatasi Security Rules dan revision transaction; hadiah Obby masih DEMO lokal:

  • Firestore membatasi operasi world hanya pada pemilik Firebase UID, bukan REST endpoint hipotetis.
  • Cek nomor revisi (409 Conflict jika revisi usang).
  • Checkpoint Obby hanya dicek sisi client dan belum aman untuk reward publik/kompetisi.
